# React コーディングテスト

商品一覧とカートを持つ小さなアプリを作ってください。
`src/data.js` の `PRODUCTS` を使います(データ自体は編集しないでください)。

## ルール

- 制限時間は 60 分です。全部終わらなくても大丈夫です。できたところまでで評価します。
- ステップ 1 から順番に進めてください。
- 考えていることを声に出しながら進めてください。
- [react.dev](https://react.dev/learn) と [MDN](https://developer.mozilla.org/ja/) のドキュメントは見て構いません。AI ツールの使用とコードのコピペ検索は禁止です。
- ヒント:データの絞り込みや変換には、JavaScript の配列メソッド(`map` や `filter` など)が役に立ちます。
- コンポーネントの追加やファイル分割は自由です。
- スタイルは評価しません。見た目は最低限で構いません。
- 仕様で迷ったら、自分で決めずに質問してください。

## ステップ 1:商品一覧を表示する

- 商品をカテゴリ別に分けて表示してください。カテゴリ名を見出しとして表示し、その下にそのカテゴリの商品を並べます。
- カテゴリの表示順は `PRODUCTS` に最初に登場する順(果物 → 野菜 → 飲み物)にしてください。
- カテゴリ名はコードに直接書かず、`PRODUCTS` のデータから求めてください(データに新しいカテゴリが追加されても、コードを変えずに表示されるようにします)。
- 各商品には名前と価格を `りんご ¥150` の形式で表示してください。
- 在庫がない商品(`stocked: false`)は、名前を赤色で表示してください。

表示イメージ:

```
果物
  りんご ¥150
  バナナ ¥120
  いちご ¥480   ← 在庫なしなので赤色
  ぶどう ¥398
野菜
  キャベツ ¥198
  ...
飲み物
  牛乳 ¥238
  ...
```

## ステップ 2:検索と絞り込み

- 商品一覧の上に、検索ボックスとチェックボックスを置いてください。
  - 検索ボックスのプレースホルダーは `商品名で検索`
  - チェックボックスのラベルは `在庫ありのみ表示`(初期状態はオフ)
- 検索は商品名の**部分一致**です。入力の前後の空白は無視してください。ひらがな・カタカナの区別などは考えなくて構いません。
- 検索ボックスが空のときは、全商品を表示します。
- チェックボックスがオンのときは、在庫がある商品だけを表示します。
- 検索とチェックボックスは**両方の条件を満たす**商品だけを表示します。
- 表示する商品が 1 つもないカテゴリは、カテゴリの見出しごと表示しないでください。
- 全カテゴリで表示する商品がないときは、一覧の代わりに `該当する商品がありません` と表示してください。

例:「ん」と入力し、`在庫ありのみ表示` をオンにした場合

```
果物
  りんご ¥150
野菜
  にんにく ¥298
```

(にんじんは在庫なしなので表示されない)

## ステップ 3:カート

### 一覧側

- 在庫がある商品の右に `カートに追加` ボタンを表示してください。
- 在庫がない商品には、ボタンを表示しないでください。

### カート側

- 商品一覧の下に `カート` という見出しを付けて、カートを表示してください。
- カートの各行は `りんご ×2 ¥300 [+] [−] [削除]` の形式です。
  - `¥300` はその行の小計(価格 × 数量)です。
- 行の並び順は、カートに初めて追加した順です。
- 同じ商品をもう一度 `カートに追加` したら、行を増やさずに数量を 1 増やしてください。
- `+` で数量を 1 増やし、`−` で 1 減らします。数量が 0 になったら、その行を削除します。
- `削除` で、数量に関係なくその行を削除します。
- 在庫数の上限は考えなくて構いません(いくつでも追加できます)。
- カートの最後に `合計 ¥xxx` を表示してください。
- カートが空のときは、行と合計の代わりに `カートは空です` と表示してください。
- 検索や絞り込みで一覧から商品が見えなくなっても、カートの中身はそのまま表示してください。

表示イメージ:

```
カート
  りんご ×2 ¥300 [+] [−] [削除]
  牛乳 ×1 ¥238 [+] [−] [削除]
  合計 ¥538
```

## ステップ 4:ヘッダー

- ページの一番上にヘッダーを作り、`カート (3)` のようにカート内の商品数を表示してください。
  - 数字は**数量の合計**です(行数ではありません)。例:りんご ×2、牛乳 ×1 なら `カート (3)`
- `Header` と `Cart` は、それぞれ別のコンポーネントにしてください。
- `App` から `Header` や `Cart` へ、カートのデータや更新用の関数を props で渡さないでください。それぞれのコンポーネントが直接カートのデータを参照できるようにしてください。
- カートを変更する処理(追加・増やす・減らす・削除)は 1 か所にまとめてください。ボタンを押したコンポーネント側は「何をしたいか」(例:りんごを追加したい)だけを伝え、配列の具体的な更新方法は知らなくてよい形にしてください。

## ステップ 5:使い勝手の改善

### 自動フォーカス

- ページを開いたとき、検索ボックスに自動でフォーカスが当たるようにしてください。
- HTML の `autoFocus` 属性は使わずに実装してください。

### 検索の遅延反映

- 検索ボックスに入力した文字は、入力欄にはすぐ表示されます。
- 一覧の絞り込みは、**入力が止まってから 300ms 後**に反映してください。
  - 300ms 以内に続けて入力した場合は、最後の入力から改めて 300ms 待ちます。
  - 例:「り」「ん」「ご」を素早く入力したら、絞り込みは「りんご」で 1 回だけ行われます。
- `在庫ありのみ表示` チェックボックスは、遅延させずにすぐ反映してください。
- この「値の変化を一定時間遅らせる」処理は、別ファイルに切り出し、他のコンポーネントからも同じように使える形にしてください。
- 入力の途中でコンポーネントが画面から消えた場合でも、待機中の処理が残らないようにしてください。
